# Installateurs de Warmup

Les fichiers d'installation sont trop lourds pour être rangés dans le dépôt (GitHub refuse plus de 100 Mo par fichier).
Ils se téléchargent depuis la page **Releases** :

**[Télécharger la dernière version](https://github.com/RomainVnh/warmup/releases/latest)**

| Système | Fichier à télécharger |
| --- | --- |
| Windows 10 ou 11 | `Warmup-<version>-win-x64.exe` |
| macOS (puce Apple) | `Warmup-<version>-mac-arm64.dmg` |

À l'installation, l'application est vierge : aucun jeu ni chiffre d'exemple. Elle lit le matériel du PC et cherche les jeux installés.

Les installateurs ne sont pas encore signés : Windows et macOS affichent un avertissement au premier lancement.
La marche à suivre est dans [`INSTALLER-WARMUP.txt`](../INSTALLER-WARMUP.txt).
