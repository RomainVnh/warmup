INSTALLER WARMUP
================

Les installateurs se téléchargent sur GitHub, page « Releases » du dépôt :
  https://github.com/RomainVnh/warmup/releases

Ils ne sont pas dans le code du dépôt : GitHub refuse les fichiers de plus de
100 Mo dans un dépôt, et chaque installateur en pèse près de 200.
Après fabrication, ils sont aussi dans le dossier « installateurs » du projet :

  Warmup-0.3.0-mac-arm64.dmg    pour un Mac récent (puce Apple)
  Warmup-0.3.0-win-x64.exe      pour un PC Windows 10 ou 11


SUR UN PC WINDOWS
-----------------
1. Copiez Warmup-0.3.0-win-x64.exe sur le PC (clé USB, partage, envoi).
2. Double-cliquez dessus.
3. Windows affiche « Windows a protégé votre ordinateur », car l'installateur
   n'est pas encore signé. Cliquez sur « Informations complémentaires »,
   puis sur « Exécuter quand même ».
4. Choisissez le dossier d'installation, puis « Installer ».
5. Warmup apparaît sur le Bureau et dans le menu Démarrer.

Pour le retirer : Paramètres de Windows > Applications > Warmup > Désinstaller.


SUR UN MAC
----------
1. Double-cliquez sur Warmup-0.3.0-mac-arm64.dmg.
2. Faites glisser Warmup dans le dossier Applications.
3. Au premier lancement, macOS refuse l'ouverture, car l'application n'est pas
   encore signée. Ouvrez Réglages Système > Confidentialité et sécurité,
   descendez jusqu'à « Warmup a été bloqué », puis cliquez sur
   « Ouvrir quand même ».

Pour le retirer : mettez Warmup à la corbeille depuis le dossier Applications.


REFAIRE LES INSTALLATEURS APRÈS UN CHANGEMENT
---------------------------------------------
Dans le dossier du projet :

  npm run installateur            fabrique l'installateur Mac
  npm run installateur:windows    fabrique l'installateur Windows

Les deux commandes fonctionnent depuis ce Mac. Comptez une à deux minutes.
Pour changer le numéro de version, modifiez « version » dans package.json.


CE QUE L'ON VOIT APRÈS L'INSTALLATION
-------------------------------------
Une application vide : aucun jeu, aucun ami, aucun chiffre d'exemple. Warmup
crée le compte, lit le matériel du PC, puis cherche les jeux installés.
Seul le compte admin retrouve la version de test, avec ses jeux d'exemple.


CE QUI MANQUE ENCORE
--------------------
- Signature : sans certificat (payant) d'Apple et de Microsoft, les deux
  systèmes affichent un avertissement au premier lancement.
- Mise à jour automatique : pour une nouvelle version, il faut réinstaller.
- Mac à processeur Intel : seul l'installateur pour puce Apple est fabriqué.
- L'installateur Windows a été fabriqué depuis le Mac, mais pas encore essayé
  sur un vrai PC.
